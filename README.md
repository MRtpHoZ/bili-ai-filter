# 清流 · B站 AI 内容过滤器

刷 B 站时看不见 AI 生成的视频，但不是靠猜，是靠 B 站自己说的话。

B 站在视频接口里公开了内容标注字段，AI 内容标注有「含AI生成内容」「作者声明：该视频使用人工智能合成技术」。本扩展直接读这个字段，把命中项从推荐流里拿掉。不训练模型、不上传图片、不调用任何第三方接口。

## 数据来源

```
GET https://api.bilibili.com/x/web-interface/view?bvid=BVxxxx
→ data.argue_info.argue_msg
→ data.title / data.desc（关键字过滤用，同一个响应里就有，不新增请求）
```

已观测取值：`含AI生成内容`、`作者声明：该视频使用人工智能合成技术`、`含虚构演绎内容`、`个人观点，仅供参考`、`专业动作，非专业人士请勿模仿`。

**这是通用提示通道，AI 只是其中一种取值。必须精确匹配，不能模糊包含判断。**

## 功能（v0.1）

- 首页 / 频道页 / 搜索页 / 视频页的卡片按 bvid 查接口，命中选中类型则淡出 150ms 后隐藏。
- 隐藏方式在面板里二选一：**补位**（默认，隐藏后后面视频顶上来，不留空位）或 **占位**（原位留一块灰卡，排版不变）。
- 默认只过滤「含AI生成内容」「作者声明：该视频使用人工智能合成技术」，其余类型在面板里自行勾选；类型从实际数据动态发现并累积。
- 关键字过滤：面板里一行填一个词，命中视频标题或描述即过滤（大小写不敏感，与官方标注共用隐藏通道，有词就生效、没词不生效，不设第二个开关）。
- 无限滚动、「换一换」产生的新卡片由 `MutationObserver` 捕获，只查询即将进入视口的卡片（`IntersectionObserver` 提前 200px）。
- 视频页顶部挂提示条（「此视频含 AI 生成内容」），不做自动跳回。
- 占位模式：灰卡上带「撤销」；补位模式：左下角浮条「已隐藏 N 个视频 · 撤销」。点撤销恢复显示并永久记住该 bvid。
- 请求并发上限 4、单请求超时 2000ms、同一 bvid 结果缓存 24h；超时/报错/风控一律保持显示（宁可漏杀不可误杀）。
- 全部数据存 `chrome.storage.local`，只向 `api.bilibili.com` 发请求。

## 安装（未打包加载）

1. Chrome 地址栏打开 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选本目录（含 `manifest.json` 的那一层）
4. 打开 `www.bilibili.com` 首页，点扩展图标打开面板确认总开关与类型勾选

## 目录

```
manifest.json      MV3 清单（host_permissions 只开 api.bilibili.com）
core.js            纯逻辑，无浏览器依赖，可被 node 测试加载
background.js      服务 worker：并发受限的接口请求 + 24h 缓存 + 风控退避
content.js         内容脚本：卡片发现 / 观察器 / 隐藏与「我看错了」
popup.html/js/css  面板：总开关、类型多选、本页已过滤数量
scripts/           数据源核验脚本（手动）
test/              纯逻辑单测
```

## 修选择器只改一处

卡片 DOM 选择器集中在 `content.js` 顶部的 `CARD_SELECTORS` 数组。首页改版导致选择器失效时，是安全的一侧（卡片全部可见），不会误杀。

## 已知取舍

两种隐藏方式各有代价，所以做成选项让用户自己选：

- **占位**：零排版 bug，但被隐藏的位置是一块灰卡。
- **补位**：隐藏后后面视频顶上来，但首页行高由 B 站写死、改不动，顶上来的卡片个别会落进不同行高被拉伸（实测幅度 40px 以内、无重叠无溢出）——这是补位的固有代价，无法消除。
