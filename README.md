# 清流 · B站 AI 内容过滤器

刷 B 站时看不见 AI 生成的视频，但不是靠猜，是靠 B 站自己说的话。

B 站在视频接口里公开了内容标注字段，AI 内容的值是「含AI生成内容」。本扩展直接读这个字段，把命中项从推荐流里拿掉。不训练模型、不上传图片、不调用任何第三方接口。

## 数据来源

```
GET https://api.bilibili.com/x/web-interface/view?bvid=BVxxxx
→ data.argue_info.argue_msg
```

已观测取值：`含AI生成内容`、`含虚构演绎内容`、`个人观点，仅供参考`、`专业动作，非专业人士请勿模仿`。

**这是通用提示通道，AI 只是其中一种取值。必须精确匹配，不能模糊包含判断。**

## 状态

v0.1 开发中：只读官方标识，默认只过滤「含AI生成内容」，其余类型由用户自行勾选。
